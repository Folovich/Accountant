# Accountant

Учебный сайт для расписания бухгалтерских консультаций. Frontend находится в `frontend/`, Spring Boot API — в `backend/`. Приложение обслуживает оба по одному адресу; cookie сессии и API-запросы работают с того же origin.

## Требования

- Windows
- JDK 21
- В корне проекта файл `start.bat`

## Запуск

Дважды нажмите `start.bat` или запустите его из PowerShell. В меню выберите:

1. **Локально** — сервер слушает порт 8080. Откройте <http://localhost:8080>.
2. **Публично** — сервер слушает порт 4242. Откройте <http://89.109.17.6:4242>.

Окно запуска оставьте открытым, пока сайт должен быть доступен. Для остановки нажмите `Ctrl+C`.

## Настройка публичного доступа

Публичный режим использует предоставленные параметры роутера:

- внешний TCP-порт: `4242`
- внутренний адрес компьютера: `192.168.0.107`
- внутренний TCP-порт: `4242`
- ссылка: <http://89.109.17.6:4242>

Проверьте, что правило переадресации направлено на `192.168.0.107:4242`. В брандмауэре Windows разрешите входящие TCP-подключения к порту 4242. Если правило нужно добавить вручную, запустите PowerShell от имени администратора и выполните:

```powershell
New-NetFirewallRule -DisplayName "Accountant website 4242" -Direction Inbound -Protocol TCP -LocalPort 4242 -Action Allow
```

Проверяйте публичную ссылку с устройства, отключённого от домашнего Wi-Fi (например, с телефона через мобильный интернет). Публичный доступ не будет работать, если провайдер блокирует входящие подключения или IP `89.109.17.6` не является публичным адресом роутера.

## Важно о публичном режиме

- Публичный режим отключает H2 Console.
- Сайт доступен по обычному HTTP, HTTPS не настроен. Не вводите реальные или повторно используемые пароли.
- Это учебное приложение, не предназначенное для хранения реальных персональных данных или открытого production-доступа.
- Компьютер должен быть включён, подключён к интернету, а `start.bat` должен продолжать работать.
